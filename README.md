## Part B — Python Hack assembler
- `capstone/assembler.py` implements source cleaning, a two-pass symbol/code translation pipeline, predefined symbols, variable allocation, and duplicate-label warnings.
- Run the built-in tests:

```powershell
python .\assembler.py --self-test
```

- Assemble a program:

```powershell
python .\assembler.py Add.asm
```

The assembler was compared against the official Nand2Tetris assembler using `Add.asm`, `Max.asm`, `Rect.asm`, and `Pong.asm`. Evidence is in `capstone/ScreenShots/PART-B/`.

## Part C — Box program (K = 02)
For roll number `2501730302`, K is `02`. The program draws a 48-pixel-wide, 20-row-high rectangle beginning at screen row 2 while a key is held, and clears the rectangle after the key is released.

- `capstone/Box.asm` — Hack assembly source.
- `capstone/Box.hack` — 47-instruction machine-code output generated by the Python assembler.

Generate the machine code again with:

```powershell
python .\assembler.py Box.asm
```

The program was demonstrated in the Nand2Tetris **CPU Emulator**. Part A's HDL chips were separately validated with their official Hardware Simulator tests. Part C was not run directly on the integrated `Computer.hdl` chip.
